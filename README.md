# Sales Performance Analysis 2024-2025

**Analyzed 1000 sales transactions worth ₹2.18Cr (21.84M)**


## 📊 Dashboard Overview
- **Total Sales:** ₹21.84M
- **Total Orders:** 1000
- **Top Product:** Laptop - ₹82.33L (38%)
- **Top Category:** Electronics - 76.48%

## 🛠️ Tools Used
- Excel - Data Cleaning
- MySQL Workbench - 8 Business Queries
- Power BI - Interactive Dashboard

## 🔍 Key Insights
1. **Electronics dominates:** ₹16.7M (76.48%) of total revenue
2. **Laptop is hero product:** ₹82.33L sales, 4x more than 2nd product
3. **UPI preferred:** 358 orders (35.8%) - Digital payments = 82.4%
4. **Seasonality:** Peak in April (₹2.5M), lowest in Nov-Dec (₹1.4M)
5. **Furniture second:** ₹2.24M (10.27%)
